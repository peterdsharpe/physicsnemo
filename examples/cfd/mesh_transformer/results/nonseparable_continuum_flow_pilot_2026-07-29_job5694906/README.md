# Nonseparable continuum flow — reduced-budget pilot

## Exploratory result

The path-length-scaled flow exhibited the predicted resolution behavior. Its
cross-channel error stayed between 48% and 50% when the same profile family
was represented with 4, 8, 16, or 32 layers. The previous recurrence rose
from 41% at eight layers to 106%, 129%, and 170% at 4, 16, and 32 layers.

The pilot did not yet support frequency transfer. The physical flow retained
91%--95% error on fast fields and was slightly worse than the sorted-flow
control. It also remained underfit in distribution relative to fixed
truncation (50% versus 30%).

Because this run used only 750 updates and one eighth of the planned training
data, it is an optimization and effect-size pilot only. A full-budget
single-seed check follows before any formal run.
