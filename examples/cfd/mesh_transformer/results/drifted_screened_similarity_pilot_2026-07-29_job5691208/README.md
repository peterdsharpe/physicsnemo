# Similarity-coordinate pilot

This directory preserves the underpowered 500-step signal check for the
registered raw-versus-similarity coordinate factorial.

The pilot is not a scientific verdict. All four arms trained stably, and the
raw pointwise and raw hybrid arms reproduced the preceding supervision pilot
exactly on the scientific metrics. The similarity arms changed the low- and
high-screening responses enough to make the registered formal comparison
discriminating, without revealing a numerical failure.

- `pilot/` contains one report for each coordinate-by-loss arm.
- `STATUS` records successful terminal completion.

The five-seed, 4,000-step formal run is required for any belief update.
