# Coupled physical-order composition pilot

This directory preserves the underpowered 500-step signal check for the
registered coupled-mode composition study.

The pilot is not a scientific verdict. The analytic oracle was exact, and the
sorted learned generator predicted exactly zero layer-order contrast. The two
physical-order seeds recovered 92.8% and 94.5% of the true contrast, versus
0.6% for the pooled model. Relative to pooling, they reduced cross-channel
error by factors of 6.1--7.8 on unseen twist rates and 9.4--12.7 when the
composition length doubled.

The registered five-seed, 4,000-step comparison is required to decide the
claim.

- `pilot/` contains the five signal-check reports.
- `STATUS` records successful terminal completion.
