# Historical architecture chapters

These are superseded MeshTransformer and early ISLA chapters, kept outside
the live book's chapter list. Their numerical claims describe the historical
experiments and should be read with the dated lab notebook.

The `figures/` directory contains the original rendered images, and `data/`
contains the Navier–Stokes gallery fields consumed by the archived nonlinear
chapter. Some figures depend on original checkpoints and temporary training
histories that are no longer available; the PNGs are retained as evidence.
The archived `figures.py` script documents how they were produced and still
requires the retired example modules and its recorded session inputs.

The original file layout is recoverable at commit
`10b0990100f58ff9004cdcbd3b2d40db4c759b0e`; the retired model and example code
are retained at `mt1-final`. See [the archive guide](../../ARCHIVE.md) for
restoring the unused hero dataset and historical checkpoints.
